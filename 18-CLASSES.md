# CLASSES & SUBCLASSES

This is the class reference for the story. I want characters to have D&D-style roles that actually fit how they fight, think, travel, use magic, and live in the world.

A character does not have to fit perfectly into one class. Multiclassing, unusual builds, homebrew subclasses, racial traditions, and story-specific abilities can all exist.

## BARBARIAN

Good for characters who rely on physical power, endurance, instinct, and fury.

Possible subclasses:

- Path of the Berserker
- Path of the Totem Warrior
- Path of the Zealot
- Path of the Beast
- Path of Wild Magic
- Path of the Giant
- Path of the World Tree
- Path of the Storm Herald
- Aethelgard: Path of the Iron Marrow

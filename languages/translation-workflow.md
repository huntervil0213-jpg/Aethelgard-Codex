# Translation Workflow

This is the workflow used when converting Aethelgard dialogue into or out of Common.

## Step 1 — Identify language

Determine the speaker's native language and the register being used.

## Step 2 — Check the canonical dictionary

Use an existing root whenever one exists. Never replace a canonical word with a new synonym merely because it sounds better.

## Step 3 — Build the sentence using canonical grammar

Apply the language's documented syntax, morphology, tense, possession, plurality, and honorific rules.

## Step 4 — Check cultural register

A royal proclamation, battlefield command, insult, prayer, tavern conversation, and private conversation should not automatically use the same register.

## Step 5 — Produce three reference layers

**Native:** the constructed-language sentence.

**Gloss:** a compact word-by-word reference for the editor.

**Common:** the natural English/Common meaning intended for the reader.

## Step 6 — Continuity check

Confirm that names, titles, pronouns, terminology, and previously established translations remain consistent.

## Step 7 — Chapter prose check

Remove unnecessary translation interruptions. Readers should normally experience the language as dialogue, not as a language lesson.

## External translator compatibility

The Codex is structured so a later translator interface can use stable entries such as:

`language + root + grammatical form + meaning`

rather than guessing from spelling alone.

This makes the system more reliable for chapter editing, dialogue generation, and continuity checks.

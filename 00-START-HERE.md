# AETHELGARD CODEX — START HERE

This is the master index for the Aethelgard worldbuilding database.

## SIMPLE MAP

- `01-WORLD.md` — World, history, geography, major civilizations
- `02-RACES.md` — Playable and sapient races
- `03-CREATURES.md` — Monsters, beasts, aberrations, undead, and other creatures
- `04-LANGUAGES.md` — Languages, scripts, dialects, translation rules
- `05-MAGIC.md` — Magic, Resonance, Flux, Ley-Tech, and magical systems
- `06-FACTIONS.md` — Kingdoms, houses, orders, guilds, and organizations
- `07-CHARACTERS.md` — Main and supporting characters
- `08-PLACES.md` — Cities, regions, landmarks, and important locations
- `09-TECHNOLOGY.md` — Ley-Tech, machinery, weapons, infrastructure
- `10-RELIGION.md` — Gods, faiths, rituals, temples, and religious vocabulary
- `11-BIOLOGY.md` — Species anatomy, physiology, reproduction, development, and medicine
- `12-CULTURE.md` — Customs, clothing, food, law, family, social structures
- `13-WRITING-SYSTEMS.md` — Alphabets, scripts, glyphs, numerals, and writing conventions
- `14-DICTIONARY.md` — Master Aethelgard vocabulary and definitions
- `15-TRANSLATION.md` — Translation guide and constructed-language rules
- `16-TIMELINE.md` — Chronology and continuity tracking
- `17-NOVEL-CONTINUITY.md` — Chapter-by-chapter canon checks

## HOW TO USE THIS

Start with this file whenever you open the repository. The numbered files are deliberately simple so the database can be navigated without reading source code.

The more detailed material will live inside these categories and their subfolders. Cross-references should use the same simple numbering system.

## CORE RULE

Everything in this Codex is subordinate to established novel canon. New worldbuilding may expand the setting, but it must not silently contradict an established event, character fact, reveal, relationship, location, language rule, or plot outcome.
